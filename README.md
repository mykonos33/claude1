# 오목눈이 아이스크림 대결

유민이와 소민이가 아이스크림 가게 사장님이 되어 오목눈이 손님을 맞는 태블릿용 HTML 게임입니다.
`index.html` 파일 하나로 돌아가고, 설치 없이 브라우저에서 열면 됩니다. 가로 화면에 맞춰 만들었고 세로 화면도 지원합니다.

## 진행 방식
1. 사장님(유민 또는 소민)을 고르면 나머지 한 명은 컴퓨터가 맡습니다.
2. 상대 실력(살살 / 보통 / 진심)을 고릅니다.
3. 대결을 고릅니다: 주문 받기, 철판 롤, 오늘의 대결(두 게임 점수 합계).

## 게임 1: 주문 받기 대결 (90초)
- 그릇(컵/콘)을 고르고, 맛(딸기·오레오·우유·초코)을 아래부터 쌓고, 토핑(체리·스프링클·하트쿠키)을 올린 다음 손님을 톡 누르면 줍니다.
- 시간이 갈수록 주문이 어려워집니다(1스쿱 → 2스쿱+토핑 → 3스쿱).
- 점수: 기본(2 + 스쿱 수 + 토핑) + 빨리 준 보너스 + 콤보 보너스. 리본 손님은 2배.
- 틀리게 주면 콤보가 끊기고 손님이 기다리는 시간이 3초 줄어듭니다.

## 게임 2: 철판 롤 대결 (80초)
- 붓기(맛 고르기) → 다지기(철판 8번 톡톡) → 펴기(문지르기) → 말기(타이밍 맞춰 4번).
- 점수: 3 + 롤 품질(완벽 2, 좋아 1) + 빨리 만든 보너스 + 올 퍼펙트 보너스. 리본 손님은 2배.

## 캐릭터 특징
- 유민(꼼꼼 사장님): 콤보 보너스가 1점 더.
- 소민(귀요미 사장님): 리본 손님(2배)이 더 자주 옵니다.

## 그림
- `assets/birds/`: 유민이가 AI로 만든 오목눈이 그림(아이스크림 가게, 오캡 페스티벌, 오트박스, 둥지)에서 배경을 지우고 오려낸 손님들. 리본 달린 아이들(`bow_*`)과 하트핀 오목눈이(`nest_r`)는 점수 2배 리본 손님입니다.
- `assets/girls/`: 캠핑 그림에서 오려낸 유민·소민 캐릭터.
- 그림을 바꾸려면 같은 이름의 webp 파일만 바꾸면 되고, 손님 목록은 `BIRDS_NORMAL`, `BIRDS_SPECIAL`에서 고칩니다.

## 조절하기
`index.html`의 스크립트 맨 위 "설정값" 부분에서 시간, 다지기 횟수, 펴기 거리, 컴퓨터 실력(`DIFF`), 쌓는 순서 엄격 여부(`STRICT_ORDER`)를 바꿀 수 있습니다.
점수 차가 크게 벌어지면 컴퓨터 속도가 살짝 바뀌어서 끝까지 승부가 이어지도록 해 두었습니다(`rubber` 함수).
