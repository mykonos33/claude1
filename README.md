# 오목눈이 아이스크림 대결

유민이와 소민이가 아이스크림 가게 사장님이 되어 오목눈이 손님을 맞는 태블릿용 HTML 게임입니다.
`index.html` 파일 하나로 돌아가고, 설치 없이 브라우저에서 열면 됩니다. 가로 화면에 맞춰 만들었고 세로 화면도 지원합니다.

## 진행 방식
1. 사장님(유민 또는 소민)을 고르면 나머지 한 명은 컴퓨터가 맡습니다.
2. 상대 실력(살살 / 보통 / 진심)을 고릅니다.
3. 대결을 고릅니다: 주문 받기, 철판 롤, 오늘의 대결(두 게임 점수 합계).

## 게임 1: 주문 받기 대결 (90초)
- 그릇(컵/콘)을 고르고, 맛(딸기·오레오·우유·초코)을 아래부터 쌓고, 토핑(체리·스프링클·하트쿠키)을 올린 다음 손님을 톡 누르면 줍니다.
- 시간이 갈수록 주문이 어려워집니다(1스쿱 → 2스쿱+토핑 → 3스쿱).
- 점수: 기본(2 + 스쿱 수 + 토핑) + 빨리 준 보너스 + 콤보 보너스. 리본 손님은 2배.
- 틀리게 주면 콤보가 끊기고 손님이 기다리는 시간이 3초 줄어듭니다.

## 게임 2: 철판 롤 대결 (80초)
- 붓기(맛 고르기) → 다지기(철판 8번 톡톡) → 펴기(문지르기) → 말기(타이밍 맞춰 4번).
- 점수: 3 + 롤 품질(완벽 2, 좋아 1) + 빨리 만든 보너스 + 올 퍼펙트 보너스. 리본 손님은 2배.

## 게임 3: 오목눈이 축제 보드게임 (`festival.html`)
- 주사위를 굴려 축제 거리를 돌며 오목눈이 손님을 모으는 차례 게임. 둘 다 도착하면 끝.
- 칸: 손님(1명), 리본 손님(2점), 가챠(1~3명), 아이스크림 퀴즈(주문을 기억해서 맞히면 2명), 이벤트(귤 100개 당첨, 비, 바람 등), 갈림길(지름길 7칸 / 축제 거리 14칸).
- 세트(리본·둥지·귤 축제·솜뭉치)를 모으면 보너스, 먼저 도착하면 +3, 나중 도착 +1.
- 운이 크게 작용해서 소민이(컴퓨터)도 충분히 이길 수 있게 만들었고, 퀴즈와 갈림길 선택이 유민이의 실력 요소입니다.

## 게임 모음 (`games.html`)
모든 게임으로 가는 첫 화면입니다. 아래 새 게임들의 "다른 게임" 버튼도 이 화면으로 돌아옵니다.

## 게임 4: 소민이 톡톡 놀이방 (`somin.html`)
- 소민이(만 31개월) 전용. 점수·시간·실패가 없고, 어디를 눌러도 소리와 반짝이가 나옵니다. 글자를 몰라도 되게 아래 그림 버튼 4개로 장면을 바꿉니다.
- 🐦 들판: 오목눈이를 누르면 짹짹 통통. 땅을 누르면 꽃이 피고 하늘을 누르면 별·나비가 떠오릅니다.
- 🍦 냠냠: 아이스크림을 끌어다 주거나 톡 누르면 오목눈이가 먹고, 맛 이름을 말해 줍니다.
- 🙈 까꿍: 선물 상자·바구니·버섯을 누르면 숨어 있던 오목눈이가 "까꿍!"
- 🎈 풍선: 터뜨릴 때마다 하나, 둘, 셋… 열까지 세어 줍니다. 풍선에 매달린 오목눈이는 우산을 타고 내려옵니다.
- 집 버튼과 소리 버튼은 실수로 눌리지 않게 1초 꾹 눌러야 동작합니다. 말소리는 기기의 한국어 음성(브라우저 음성 합성)을 씁니다.

## 게임 5: 오목눈이 생일 파티 준비 (`party.html`)
- 태블릿 한 대에서 둘이 한 팀으로 하는 90초 협동 게임. 점수를 하나로 합쳐 별 3개를 모읍니다.
- 유민: 주문대로 빵 → 크림 → 장식을 올려 케이크를 만듭니다. 4번째 케이크부터는 주문이 몇 초 뒤 가려져서 기억해서 만들어야 합니다(눌러서 다시 볼 수 있지만 기억 보너스 3점이 사라짐).
- 소민: 풍선을 터뜨리면 1점씩. 8개를 터뜨리면 "응원 파워"가 켜져 8초 동안 유민이 케이크 점수가 2배가 됩니다. 유민이가 케이크를 완성하면 소민이 쪽에 별 풍선(2점)이 3개 올라옵니다.
- 첫 화면의 "자리 바꾸기"로 좌우를 바꿀 수 있습니다. 설정값은 스크립트 위쪽 `CFG`.

## 게임 6: 오목눈이 하늘 대모험 (`sky.html`)
- 라이브러리 없이 WebGL로 직접 만든 3D 비행 게임입니다. 아이스크림 섬 6개, 막대사탕 나무, 무지개, 열기구, 낮 → 노을 → 밤하늘과 불꽃놀이까지 모두 코드로 그립니다(그림 파일은 안내 카드에만 사용).
- 유민이 배달 모험: 화면 왼쪽을 누른 채 끌어 조종합니다. 맛 섬 위의 고리를 통과해 스쿱을 얻고(1 → 3스쿱), 빛기둥이 선 둥지의 친구에게 배달하기를 5번. 빨리 배달할수록 별이 많고, 배달받은 친구는 뒤를 따라 납니다. 금색 고리는 부스터, 땅에 닿아도 통 튕길 뿐 실패는 없습니다. 키보드(방향키·스페이스)도 됩니다.
- 같이 하기: 유민이가 조종하는 동안 소민이가 화면 오른쪽을 톡톡 두드리면 하트가 터지고 주변 귤이 끌려옵니다.
- 소민이 하늘 산책: 오목눈이가 알아서 섬을 돌고, 화면을 두드리면 하트와 재주넘기. 귤 5개마다 친구가 한 마리씩 합류합니다. 집 버튼은 1.2초 꾹.
- 속도·별 기준 시간 등은 스크립트 위쪽 `CFG`에서 조절합니다.

## 캐릭터 특징
- 유민(꼼꼼 사장님): 콤보 보너스가 1점 더.
- 소민(귀요미 사장님): 리본 손님(2배)이 더 자주 옵니다.

## 그림
- `assets/birds/`: 유민이가 AI로 만든 오목눈이 그림(아이스크림 가게, 오캡 페스티벌, 오트박스, 둥지)에서 배경을 지우고 오려낸 손님들. 리본 달린 아이들(`bow_*`)과 하트핀 오목눈이(`nest_r`)는 점수 2배 리본 손님입니다.
- `assets/girls/`: 캠핑 그림에서 오려낸 유민·소민 캐릭터.
- 그림을 바꾸려면 같은 이름의 webp 파일만 바꾸면 되고, 손님 목록은 `BIRDS_NORMAL`, `BIRDS_SPECIAL`에서 고칩니다.

## 조절하기
`index.html`의 스크립트 맨 위 "설정값" 부분에서 시간, 다지기 횟수, 펴기 거리, 컴퓨터 실력(`DIFF`), 쌓는 순서 엄격 여부(`STRICT_ORDER`)를 바꿀 수 있습니다.
점수 차가 크게 벌어지면 컴퓨터 속도가 살짝 바뀌어서 끝까지 승부가 이어지도록 해 두었습니다(`rubber` 함수).
